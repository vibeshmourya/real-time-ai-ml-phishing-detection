# PhishShield Chrome Extension (Manifest V3)

Lightweight, privacy-preserving browser protection extension.

## Key Features
- **Real-Time Active Tab Assessment**: Evaluates the domain of the active tab.
- **Privacy-First**: No persistent user browsing history is ever transmitted or logged.
- **Instant Threat Warning Banner**: Displays red security warning for high-risk domains with action buttons (Leave Website, View Safety Guide).
- **Embedded Audio / Fast Advice**: Quick guidance directly inside the popup.
