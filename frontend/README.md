# PhishShield Web Frontend

The user-facing portal built with React.js, Tailwind CSS, and Chart.js.

## Modules
- **Public URL & Content Scanner**: One-click phishing analysis.
- **Explainable Threat Visualizer**: Interactive threat level meter, breakdown of flags, confidence score.
- **Contextual Prevention & Multimedia Player**: 30-60s awareness videos, audio warning player.
- **"I Already Clicked" Recovery Wizard**: Emergency incident containment checklist.
- **User Dashboard & Scan History**: Metrics, recent scans, reporting tracking.
- **Admin & Analyst Security Portal**: Global analytics, alert manager, threat queue.
